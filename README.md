# MOODSPACE ☾

### Твой маленький мир настроений

Атмосферное пространство, которое подстраивается под твои чувства. Светящаяся сфера, неспешные мысли и музыка, которая звучит с тобой в унисон.

**HTML + CSS + JavaScript · Без установки · Без регистрации · Без зависимостей**

## Что внутри

| Настроение | Твоя атмосфера |
| --- | --- |
| ☾ Спокойствие | Ночной синий, мягкие звёзды, ambient и piano |
| ☀ Радость | Персиковое солнце, тёплые частицы, indie pop |
| ☂ Грусть | Дождь, холодное небо, бережные слова |
| ♡ Любовь | Розовое свечение, мягкие огоньки, dream pop |
| ϟ Энергия | Неон, быстрые частицы, french house |
| ✧ Мечтательность | Космический фиолетовый, звёзды, downtempo |

- 90 оригинальных русских фраз: по 15 для каждого чувства.
- «Другая мысль» выбирает фразу без повторения предыдущей.
- «Удиви меня» всегда выбирает другое настроение.
- Музыкальные рекомендации с тремя исполнителями для каждого режима и поиском на YouTube / Spotify.
- Последнее настроение и выключение анимаций сохраняются в браузере.
- Сфера откликается на курсор. Дыхательный режим: 4 секунды вдоха, 6 секунд выдоха.
- Копирование фраз, уведомления, подсказка при первом посещении.
- Две пасхалки: коснись сферы; нажми на логотип пять раз за четыре секунды.
- Адаптивный интерфейс, клавиатурное управление, доступные подписи, системный `prefers-reduced-motion` и ручное отключение движений.

## Открыть сайт

Дважды нажми на **index.html** — сайт откроется в браузере. Интернет нужен только при переходе к музыке. Устанавливать Node.js или Python для обычного использования не нужно.

Если нужен локальный адрес для разработки, запусти из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открой [http://127.0.0.1:4173](http://127.0.0.1:4173). Остановка сервера — `Ctrl+C`.

## Публикация на GitHub Pages без команд

1. На GitHub создай **публичный** репозиторий `moodspace`.
2. Нажми **uploading an existing file** / **Add file → Upload files** и перетащи содержимое этой папки. `index.html` должен лежать в корне репозитория, а не во вложенной папке `moodspace`.
3. Сохрани файлы кнопкой **Commit changes**.
4. В репозитории открой **Settings → Pages**.
5. Выбери **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
6. Дождись завершения сборки: GitHub покажет адрес `https://USERNAME.github.io/moodspace/`.

Для GitHub Pages не нужны сборка, платные API или настройка сервера. Все локальные пути относительные; `.nojekyll` отключает ненужную обработку Jekyll. Папки `.openai` и файл `build.mjs` служат дополнительному размещению через Sites и не нужны для GitHub Pages.

## Как поменять текст или музыку

Все фразы и подборки находятся в объекте `MOODS` в начале `script.js`. `phrases` содержит мысли, `artists` — исполнителей, `query` — поисковый запрос. Палитры шести настроений описаны в конце `style.css` через `html[data-mood=...]`.

## Проверки для разработчика

Если установлен Node.js, выполни `node verify.mjs` и `node --check script.js`. Для подготовки дополнительного размещения через Sites — `node build.mjs`. Зависимостей нет.

## Приватность и музыка

Сайт не подключает аналитику, шрифтовые CDN, cookies, встроенные плееры или платные API. Ключи `moodspace:mood`, `moodspace:motion`, `moodspace:visited` сохраняются только в `localStorage` твоего браузера. Если браузер запрещает это хранилище, сайт продолжает работать без сохранения.

Копирование зависит от разрешений браузера. На HTTPS используется Clipboard API; при открытии локального файла применяется совместимый резервный способ. При отказе сайт предложит выделить мысль вручную.

Аудиофайлов в проекте нет. Ссылки открывают поиск сторонних платформ в новой вкладке: там действуют их условия, региональные ограничения и требования к аккаунту. Поиск — рекомендация, а не гарантированная готовая подборка. Дыхательный режим — необязательная визуальная пауза, выбирай комфортный ритм.

Музыкальные направления подобраны редакционно. Справочные страницы: [Ólafur Arnalds](https://olafurarnalds.com/), [Ben Böhmer / Anjunadeep](https://anjunadeep.com/artists/67093-ben-bhmer), [Tycho — Awake](https://music.apple.com/us/album/awake/793928184).
